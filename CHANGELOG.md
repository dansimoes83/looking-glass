# Changelog

All notable changes to Looking Glass will be documented here.

## [1.0.0] - 2026-09-16

### Added

- First public model-agnostic release.
- Canonical Looking Glass framework.
- Canonical AI instruction file.
- Evidence model: Direct Evidence, Verified External Evidence, and Inference.
- Evidence-Only as the default mode.
- Adaptive diagnostic flow.
- Explicit rewrite checkpoint.
- LinkedIn, portfolio, résumé, and role-comparison use cases.
- Usage guides for ChatGPT, Gemini, generic AI conversations, Cursor, and Codex.
- Fictional worked examples.
- CC BY 4.0 licensing and attribution guidance.

### Changed from the earlier agent version

- Expanded scope from LinkedIn-only positioning to professional narrative diagnosis.
- Removed Tech & Digital as a hard boundary.
- Replaced mandatory multi-module interviews with adaptive questioning.
- Removed unnecessary authorization gates while preserving explicit approval before public rewriting.
- Made the framework independent from a specific AI provider.
- Separated framework, AI instructions, and installation guides.

### Preserved

- Diagnose before writing.
- Preserve identity over optimization.
- No invented evidence.
- No inflated seniority.
- Clear distinction between observation and inference.
- Explicit limitations when evidence is missing.
